# ⚛️ The Periodic Table of Varunraj

### An Interactive Developer Portfolio Engineered as a Living Laboratory

> **Code is the element. Curiosity is the catalyst. Every project is an experiment.**

Welcome to **The Periodic Table of Varunraj** — an experimental, cinematic developer portfolio where software engineering meets the visual language of a scientific laboratory.

Instead of presenting a conventional portfolio with static cards and ordinary sections, this experience treats **skills as elements, projects as experiments, achievements as measurements, certifications as laboratory records, and the developer profile as a scientific subject file.**

The entire website is designed to unfold as a **story-driven interactive laboratory** as the visitor scrolls.

---

## 🧪 The Concept

Most developer portfolios follow the same structure:

`Hero → About → Skills → Projects → Resume → Contact`

This portfolio takes a different approach.

# 🎨 Design Philosophy

The visual system intentionally avoids the typical:

> gradient background + glass cards + generic developer illustration

approach.

Instead, it uses a darker scientific aesthetic with:

* Laboratory-inspired typography
* Technical labels
* Element symbols
* Measurement interfaces
* Scientific terminology
* Atmospheric particles
* Grain and texture
* Controlled motion
* Experimental transitions
* Sequential storytelling

The interface is designed to feel like a **classified research facility from the future**.

---

# 🧠 Engineering Principles

This project follows several principles:

### 01 — Identity over Templates

The portfolio should be recognisable even without seeing the developer's name.

### 02 — Motion with Purpose

Animations are used to communicate transitions, hierarchy and discovery — not simply decoration.

### 03 — Storytelling

Each section contributes to the larger narrative.

### 04 — Componentisation

Every major experience is isolated into reusable React components.

### 05 — Data-driven Content

Portfolio information is separated from presentation wherever practical.

### 06 — Progressive Discovery

Information is revealed progressively as the visitor explores the page.

# 🚀 Running Locally

## Prerequisites

Make sure you have installed:

* Node.js
* npm

## Installation

Clone the repository:

```bash
git clone <YOUR_REPOSITORY_URL>
```

Navigate into the project:

```bash
cd the-periodic-table-of-varunraj
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will be available through the local Vite development server.

---

# 🏗️ Production Build

Create an optimised production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

Run TypeScript validation:

```bash
npm run lint
```

# ⚡ Performance & Interaction

The application uses several techniques to keep the experience responsive:

* Component-based rendering

* Controlled animation states

* Session-aware introduction playback
* Data-driven rendering
* Responsive layouts

The scroll navigation also tracks the active section automatically, allowing the periodic navigation to respond to the visitor's position.
